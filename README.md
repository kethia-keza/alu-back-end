# alu-back-end

Back-end projects using Python and REST APIs.

## api

Script that uses a REST API to gather an employee's TODO list progress.

- `0-gather_data_from_an_API.py`: takes an employee ID and prints their completed tasks.

## Requirements
- Python 3.8.5 on Ubuntu 20.04 LTS
- `requests` module
- PEP8 (pycodestyle) compliant

## Usage
./api/0-gather_data_from_an_API.py <employee_id>
